# Decision Tree Classification using Python

## Aim
To implement a Decision Tree machine learning algorithm and perform classification using Python and Scikit-learn.

## Description
This project uses a Decision Tree classifier to classify Iris flowers into three species using their sepal and petal measurements.

## Features
- Object-oriented Python implementation.
- Iris dataset from Scikit-learn.
- Training and testing dataset split.
- Decision Tree classification.
- Accuracy and classification report.
- Prediction of flower species.

## Applications
- Used in Advanced data processing
- Used in Decision Algos

## Requirements
- Python 3
- Scikit-learn

## Installation
```bash
pip install -r requirements.txt
```

## Execution
```bash
python decision_tree.py
```

## Algorithm Workflow
1. Load the Iris dataset.
2. Split the dataset into training and testing sets.
3. Train the Decision Tree classifier.
4. Predict flower classes.
5. Evaluate the model using accuracy and classification metrics.

## Result
The Decision Tree classifier is trained and evaluated on the Iris dataset. The program displays its classification metrics and a sample prediction.
